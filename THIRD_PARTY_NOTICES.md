# 第三方声明与素材来源 / Third-party notices and asset provenance

Each HTML carries the fonts and scripts it needs at runtime. The fonts use the SIL Open Font License 1.1, and Three.js uses MIT. Original copyright and license notices remain embedded in the corresponding HTML. The repository's MIT license covers original code and documentation. Third-party components retain their respective licenses.

《月落之海》的三幕海景和月相仪底图、《咔嗒！》的四位黏土乐手，以及《失重收藏室》的展厅和五件藏品都是为作品单独生成的图像。原始 ImageGen 提示词随 HTML 保存，另有方便阅读的双语汇编。音乐和音效在浏览器中合成。README 预览图取自运行中的网页。[图像提示词及译文](docs/image-prompts.md)

The three seascapes and lunar dial texture in Sea of Selene, the four clay performers in CLACK!, and the room and five objects in Objects in Limbo were generated for these demos. The HTML retains the original ImageGen prompts, which are also collected with translations. Music and effects are synthesized in the browser. README previews are screenshots of the running demos.
